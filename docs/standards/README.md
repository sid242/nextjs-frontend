# Code Quality & Engineering Standards — Frontend Repository

Prepared for:

- Frontend: https://github.com/sid242/nextjs-frontend

## Purpose

This package provides an Antigravity implementation standard to raise the existing codebase to a consistent, maintainable, secure, type-safe, production-grade standard.

## Documents

1. `MASTER_ANTIGRAVITY_PROMPT.md` — execution contract and implementation sequence.
2. `REPOSITORY_AUDIT_FINDINGS.md` — verified observations from repository manifests, ESLint configs, and AGENTS.md.
3. `ENGINEERING_STANDARDS.md` — language-agnostic standards and code examples.
4. `FRONTEND_STANDARDS.md` — Next.js 16, React 19, TypeScript, Tailwind v4, shadcn/ui, TanStack Query, forms, state, accessibility and testing.
5. `DEPENDENCY_AND_TOOLING_POLICY.md` — dependency audit, safe upgrades, lint/type/test/CI enforcement.
6. `REFACTOR_ROADMAP.md` — phased migration strategy and acceptance gates.
